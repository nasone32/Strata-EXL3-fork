# Setting up this fork with an AI assistant

For **Qwen EXL3** or the experimental MiMo path in
[nasone32/Strata-EXL3-fork](https://github.com/nasone32/Strata-EXL3-fork), follow
**[AI_SETUP_EXL3_AMD.md](AI_SETUP_EXL3_AMD.md)**.

That guide covers the tested 3.05/4.05 bpw Qwen quants, the single tested MiMo MOPD
2.20 bpw quant, building this fork, native/disk-repacked/RAM-repacked experts,
CPU assistance, one or two GPUs, RAM limits and the local API on port **8085**.

Do not use the upstream GGUF installer to obtain an EXL3 model or a binary of this
fork. The original Strata documentation remains in [INSTALL.md](INSTALL.md) and
[UPSTREAM_README.md](UPSTREAM_README.md); its platform claims and benchmark numbers
are not validation of this fork's EXL3 changes.
